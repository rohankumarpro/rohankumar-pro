- Typeface (decided 2026-10-26): Sole Sans + Sole Serif by Luciano Perondi (CAST), both variable, from Adobe Fonts. Sans + serif from one designer is the name. Sans everywhere at rest; labels use Sole Sans at width 62 instead of a mono face; the serif italic appears only on interaction (living type in `src/scripts/live.js`) or as an `<em>` inside a heading.
- Adobe Fonts kit in use: `hik8dop` "Sansser web (Sole)" (sansser.com, www, link., sansser-hub-preview.netlify.app and its deploy previews, localhost). Both fonts are also active in the owner's Creative Cloud for Figma and Adobe apps.
