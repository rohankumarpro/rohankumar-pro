Before you start

  • Easy ones are apps: download, open, done.
  • Medium ones run in Docker. Install Docker Desktop once, then paste the commands into Terminal (Mac) or PowerShell (Windows).
  • Advanced ones need a server, for when your team or customers use it from anywhere.
  • Stuck? Paste the repo link into Claude Code or ChatGPT and ask it to install it with you, step by step.
